# Tiny Enigma

A simple browser-based AES-GCM message encryption tool.

## Features

- AES-GCM encryption
- AES-GCM decryption
- Password-based encryption
- Copy encrypted messages
- Copy decrypted messages
- Show/Hide password
- No server required
- Works entirely in the browser

## Project Structure

tiny-enigma/
│
├── index.html
├── style.css
├── script.js
└── README.md

## How To Run

1. Download the project.
2. Open index.html in your browser.
3. Start encrypting and decrypting messages.

## How To Encrypt

1. Enter your message.
2. Enter a password.
3. Click Encrypt.
4. Copy the encrypted result.

## How To Decrypt

1. Paste the encrypted text.
2. Enter the correct password.
3. Click Decrypt.
4. Read the original message.

## Security Notes

- Tiny Enigma uses AES-GCM.
- The same password must be used for encryption and decryption.
- If the wrong password is used, decryption will fail.
- Everything runs locally in your browser.

## Publishing With GitHub Pages

1. Create a GitHub account.
2. Create a new repository.
3. Upload all project files.
4. Open Settings.
5. Open Pages.
6. Select Deploy from Branch.
7. Choose main branch.
8. Save.

Your website will be available at:

https://yourusername.github.io/tiny-enigma
